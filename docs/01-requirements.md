# 01 需求

## 用户与目标

- **用户**：内容运营人员。
- **目标**：给定主题、预算、截止时间，产出一份在预算和工期内的内容活动方案；做不到时明确告知原因与缺口。

## 输入

| 字段 | 说明 | 校验 |
|---|---|---|
| topic | 活动主题 | 必填 |
| budget | 预算（模拟单位） | 必填，数字且 > 0 |
| deadline | 截止日期 YYYY-MM-DD | 必填，晚于 today |
| today | 规划起始日 | 可选，默认当天 |

合成资料：`data/materials.json`（6 个素材，含授权费与制作工时）、`data/tool_costs.json`（脚本引擎 ai 费用 2 / 1h，template 费用 1 / 2h；每天 8 工时）。

## 工具

`search_materials`（素材检索）、`generate_script`（脚本生成）、`estimate_cost`（成本估算）、`save_plan`（方案保存），均为本地函数。

## 输出

任务计划（`task_plan`，四个阶段及状态）、步骤状态（`steps`）、工具结果（`tool_results`）、费用（`cost`：预算、方案合计、剩余、各次估算）、已保存方案（`saved_plan`）或未完成原因（`message` + `gap`）。

## 范围

- 包含：CLI、单 Agent ReAct 循环、步骤状态持久化、护栏、故障注入、幂等、失败续跑、离线 Mock、OpenAI 兼容接入。
- 不包含：界面、线上部署、多 Agent、真实素材库与计费、并发与多用户。

## 成功标准

| 验收点 | 标准 |
|---|---|
| 正常完成 | 方案费用 ≤ 预算、工时 ≤ 可用工时，已保存，状态 completed |
| 缺预算或截止时间 | 状态 incomplete，列出缺失字段，不调用工具 |
| 工具失败 | 失败步骤记为 failed；调整计划或停止；已成功步骤的结果保留且不重做 |
| 预算超限 | 观察到超预算后改选替代方案并重新估算；无可行方案时返回未完成及缺口 |
| 重复执行 | 相同请求不重复调用工具、不重复保存 |
| 步数上限 | 达到上限返回明确的未完成状态 |
| 失败续跑（加分） | 只重跑失败或未完成步骤，沿用已成功结果 |
