# 05 复盘

## 最难的问题

1. **让“失败不被记为成功”成为结构保证，而不是约定**。做法是给每个成功结果分配 id，`save_plan` 只接受成功步骤的 id，并在代码里校验预算、工期和引擎一致。换引擎后必须重新估算，否则旧估算会被误用。
2. **幂等与续跑的边界**。幂等按请求内容，续跑按 run_id；已完成的运行续跑直接返回，未完成的运行沿用成功步骤。
3. **离线 Mock 的定位**。题目明确固定分支不算 ReAct，所以 Mock 只用于验证循环与护栏，并把它和真实模型放在同一接口后面，换 Key 即可切换。
